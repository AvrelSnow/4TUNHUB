# P004 - Limits and fits

**{{student_name}} · Version {{challenge_version}} · Run {{run_no}}**

A shaft of nominal size **{{D}} mm** runs in a hole. The fit is
**{{fit}}** (ISO 286, hole basis: the first class is the hole, the second the
shaft).

Using the reference table below, give, **in millimetres to three decimals**:

1. the hole's **upper limit**;
2. the shaft's **upper limit** and **lower limit**;
3. the **maximum clearance** and the **minimum clearance**
   (a negative number means the parts must be forced together);
4. the **kind of fit**: type **1** for a clearance fit, **2** for a
   transition fit, **3** for an interference fit.
