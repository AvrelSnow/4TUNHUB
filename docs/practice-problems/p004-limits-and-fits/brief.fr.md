# P004 - Ajustements

**{{student_name}} · Version {{challenge_version}} · Essai {{run_no}}**

Un arbre de cote nominale **{{D}} mm** tourne dans un alésage. L'ajustement est
**{{fit}}** (ISO 286, système de l'alésage normal : la première classe est
l'alésage, la seconde l'arbre).

À l'aide du tableau de référence ci-dessous, donnez, **en millimètres avec
trois décimales** :

1. la **cote maximale** de l'alésage ;
2. les cotes **maximale** et **minimale** de l'arbre ;
3. le **jeu maximal** et le **jeu minimal**
   (un nombre négatif signifie que les pièces doivent être emmanchées de force) ;
4. le **type d'ajustement** : tapez **1** pour un ajustement avec jeu, **2**
   pour un ajustement incertain, **3** pour un ajustement serré.
